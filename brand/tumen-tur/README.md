# Тумэн Тур — знак

Одна система: упрощённый контур Байкала + кириллица «Тумэн Тур» + плоский `#124B56`.

Знак — рифт, не мягкий загиб: почти ровная ширина, два колена, открытая бухта Ольхона. Мягкий сужающийся завиток читался как какашка; его нет.

## Цвет

| Роль | HEX |
| --- | --- |
| Знак | `#124B56` |
| Чёрный | `#111111` |
| Кремовое поле | `#F7F4EE` |
| Тёмное поле | `#0C2C30` |

Оранжевый сайта в знак не входит.

## Имя

Только **Тумэн Тур** (U+0422 U+0443 U+043C U+044D U+043D пробел U+0422 U+0443 U+0440).  
Запасная латиница: одно слово `Tumentur`, не в основном комплекте.

Шрифт слова: Noto Sans Bold, сжатие 90%, увеличенный пробел между словами. Не Arial/Inter.

## Файлы

- `export/svg/znak.svg` — мастер знака
- `export/svg/znak-favicon.svg` — тот же жест, короче и толще (16–32 px)
- `export/png/` — позиции 1–5 в цвет / чёрный / белый / инверсия
- `export/proof/` — 24/32 px, 40 мм, круги A1–A3

Сборка: `python3 build.py`
