# Тумэн Тур — единый логотип

Один набор. Знак — **контур Байкала с tumentur.ru**. Имя — **Тумэн Тур**. Линейка — **Байкал · Алтай · Монголия** словами. Алтай и Монголия картинками только в пиктограммах страниц, не в шапке.

Сборка: `python3 build_sistema.py`

## Слои

| Слой | Что | Где |
| --- | --- | --- |
| Знак | Контур озера с сайта | эмблема, favicon, печать |
| Имя | «Тумэн Тур», один кегль, Source Sans 3 Bold | шапка, бланк, пост |
| Линейка | «Байкал · Алтай · Монголия» | бланк и широкий десктоп; шапка/мобиле — без неё |

## Цвет

| Роль | HEX |
| --- | --- |
| Знак и буквы | `#124B56` |
| Чёрный | `#111111` |
| Крем | `#F7F4EE` |
| Тёмная вода | `#0C2C30` |

Оранжевый кнопки сайта в знак не входит.

## Имя

`Тумэн Тур` — U+0422 U+0443 U+043C U+044D U+043D пробел U+0422 U+0443 U+0440.  
Шрифт: Source Sans 3 (OFL, `fonts/`). Не Arial, не Inter. Латиница запасная: одно слово `Tumentur`, не в комплекте.
