## 2. Единственная схема (та же, не другая)

Горизонталь бланка:

```
[ контур с сайта ]    Тумэн Тур
                      Байкал · Алтай · Монголия
```

Горизонталь шапки сайта / мобиле:

```
[ контур с сайта ]    Тумэн Тур
```

Вертикаль поста:

```
        [ контур ]
       Тумэн Тур
   Байкал · Алтай · Монголия   ← только если ширина поста держит 14 px+
```

Плоский вектор. Без рамки, круга, подчёркивания. Версии: цвет, чёрный, белый, инверсия.

## 3. Как работать (круги по слабостям)

После каждого круга — таблица да/нет, не похвала. «Нет» — перерисуй.

**A. Край знака (слабость 6, частично 1 и 2)**  
Перечерти контур с сайта живыми кривыми. Наложение: красный = сайт, голубой = лишнее. Можно закрыть дыры и однопиксельную бахрому. Нельзя сменить жест и пропорции.

1. Это всё ещё контур с tumentur.ru?  
2. На 40 мм край не «пыль от PNG»?  
3. 24 px не какашка и не банан?  
4. Вышивка 1,5 мм: тело да; если крюк СВ нет — так и скажи, не отрезай жест ради отчёта.  
5. Не колбаса и не ББТ?

Сдай: чёрный 40 мм; 16/24/32; мелкий мастер отдельно.

**B. Вес в сетке (слабости 3 и 5)**  
Собери горизонталь знак + «Тумэн Тур» без линейки. На ширине шапки ~360–400 px знак не должен быть росчерком.

1. Пятно краски знака сравнимо с кеглем имени (не с пустым квадратом вокруг озера)?  
2. Между знаком и текстом воздух, не впритык?  
3. Э целая, «Тур» того же кегля?  
4. Не Arial/Inter «как есть», не антиква «отель»?  
5. На креме не грязно?

**C. Линейка и носители (слабость 4)**  
Линейка только там, где она читается. Нарисуй рядом: шапка без линейки / бланк с линейкой. Линейка оптически ≈ ширине имени, кегль не микротекст.

1. В шапке 400 px имя читается без второго ряда?  
2. На бланке линейка не слоган-простыня и не три курорта?  
3. Нет иконок «для смысла»?  
4. Оранжевый не в знаке?

**D. Аватар и мелочь (слабости 1 и 7)**  
16/24/32 — мелкий мастер. Telegram 48 и печать — озеро на поле `#124B56`, без кольца.

1. 24 px не клякса?  
2. Квадрат аватара не стал бейджем-компасом и не ББТ?  
3. Без имени на 16 px знак честно галочка — и это написано, не «на самом деле озеро»?

**E. Пиктограммы (слабость 8) — после логотипа, не вместо**  
Если Алтай снова крыша или M — перерисуй. Если после трёх планов всё равно «просто линии» — оставь и напиши: направления в бренде держат **слова**, пиктограммы только метки раздела.

**F. Честные остатки (слабости 2, 5, 9)**  
Три предложения, без рекламы:

- почему контур всё ещё общий для Байкала и чем сетка не ББТ / не КроссТур;  
- почему имя без озера пустое и почему орду не рисуем;  
- почему офер не в знаке.

Не дорисовывай горы «чтобы узнали все».
